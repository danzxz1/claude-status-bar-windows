# Устройство приложения

- `model.rs`: совместимые с прежней C#-версией JSON-модели, настройки, форматирование времени.
- `monitor.rs`: чтение JSONL Codex с буферизацией частичных строк и UTF-8, сопоставление окон лимитов, индекс названий.
- `integration.rs`: установка и удаление hooks, обработка stdin Claude, обёртка исходной statusLine, определение процесса Claude.
- `ui.rs`: Win32 message loop, Shell_NotifyIcon, нативные popup menu, двойная буферизация GDI, масштабирование DPI, подсказки и четыре анимации.
- `notifications.rs`: наблюдение за переходами состояния, порогами и сбросом лимитов; подавление старых и повторных событий.
- `system.rs`: включение и отключение автозапуска HKCU.
- `installed.rs`: проверка файлов установленных агентов и выбор оранжевой, голубой или двухцветной палитры.
- `i18n.rs`: встроенные и внешние JSON-каталоги, язык интерфейса Windows, ручной выбор и английский резервный перевод.
- `main.rs`: маршрутизация CLI и запуск трея.

Поток интерфейса не читает журналы: фоновый поток публикует снимки состояния через Mutex. Чтение Codex выполняется по смещениям, поэтому незавершённые строки не обрабатываются до дописывания перевода строки. Парсер ограничивает размер одной строки и не сериализует содержимое бесед обратно на диск.

Оконная процедура не получает указатель на изменяемое состояние App. Она пересылает прямые callbacks Shell (SendMessage) в собственную очередь; работа с App идёт в основном цикле. Повторные события мыши не меняют положение открытой панели. Поэтому вложенный цикл TrackPopupMenu не конфликтует с обновлением панели и не позволяет ей закрывать меню.

Владелец App удаляет значок, освобождает GDI-ресурсы и завершает фоновый поток. Именованный mutex сохраняет совместимость с C#-версией и предотвращает одновременный запуск двух экземпляров.

Локальные инструменты `.tools`, результаты сборки, диагностические снимки и архив C#-версии в `legacy` не публикуются. Cargo.lock включается в репозиторий. Для публикации используются только исходники Rust, документация, демонстрационные изображения и workflow.

Общий или два значка используют независимые идентификаторы Shell_NotifyIcon. Настройки панели задают геометрию регионов для рисования и подсказок. Уведомления отправляются с ограничением частоты, тихий режим очищает очередь.

Цвет общего значка определяется установленными агентами с включённым отслеживанием, независимо от активности сессий и выбора видимых блоков. Для двухцветной палитры цвет вычисляется по координате образца относительно середины значка; анимация меняет геометрию, а не положение цветовой границы.

Флаги отслеживания передаются фоновому потоку через AtomicU8. Выключенный Codex не создаёт Monitor, существующий читатель освобождается; выключенный Claude не читает состояния. Hooks Claude проверяют настройку перед записью и автоматическим запуском. Существующие файлы не удаляются; время повторного включения Claude служит нижней границей актуальности состояния. Отключение источника также очищает его историю уведомлений в памяти.

`locales/en.json` и `locales/ru.json` содержат переводы с устойчивыми ключами и именованными подстановками. Каталоги встроены через include_str!, внешние файлы загружаются из locales рядом с exe. Центральный слой рендеринга переводит строки приложения; пользовательские названия и пути идут через отдельный путь без перевода.
